# Police Attendance & Schedule Management System

A responsive multi-page front-end demo based on the supplied concept image. Built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — sign in
- `register.html` — create a demo account
- `dashboard.html` — overview and recent attendance
- `attendance.html` — record, search and delete attendance
- `schedule.html` — create, search and delete shifts
- `duties.html` — allocate, search and delete duties
- `reports.html` — totals, CSV exports and demo data reset
- `profile.html` — edit current profile

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Recommended: install the VS Code **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.
4. Or from a terminal in this folder run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Demo notes
- Create an account through **Create an account**.
- Data is saved in browser `localStorage`; the signed-in session uses `sessionStorage`.
- The data remains in the same browser profile, but is not synced between devices. Clearing browser data can remove it.
- This is a college-project prototype, not a production police system. The demo stores passwords in local browser storage and has no server-side authentication, role enforcement, encrypted database, audit trail, or multi-user synchronization. Do not enter real personal, police, or operational data.
- For production, add a secure backend/API, a database (e.g. PostgreSQL or MySQL), password hashing, server-enforced role-based access control, HTTPS, audit logs, backups, validation and a reviewed retention/privacy policy.
